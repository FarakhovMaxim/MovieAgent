MovieAgent — учебное приложение с чат-ассистентом, который советует фильмы. В нём есть чат, история диалогов и карточка с подборкой фильмов. Ответы подготовлены заранее.

Версия для iOS сделана на UIKit, версия для Android — на Jetpack Compose. Чтобы запустить iOS, открой IOSImplementation.xcodeproj в Xcode. Для Android открой папку android в Android Studio.

Сравнение двух версий я написал в comparison.md.
